# Daily Engineering Task

Read control files, fetch/inspect branch/PR, run `make test`, then ask: “What is the highest-value remaining blocker preventing PORTFOLIO COMPLETE — LOCAL-FIRST SCOPE?” Continue that P0 vertical slice. Do not select documentation polish, cosmetic refactors, extra integrations, or P2 work while mandatory blockers remain. Verify current Backstage APIs before adding packages. Execute templates and generated tests before changing status. Update backlog/status, commit/push branch only, and report exact live portal/scaffolder evidence and gaps.
