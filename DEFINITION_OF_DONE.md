# Definition of Done

- **Level 1:** catalog/template/standard contracts tested.
- **Level 2:** current Backstage frontend/backend and Catalog run locally.
- **Level 3:** developer → Create → executed Production API scaffold → runnable service → catalog/docs → real scorecard; legacy/drift failure demonstrated.
- **Level 4:** AI path, reproducible CI/demo, accurate status table and no unexecuted-template claim.
